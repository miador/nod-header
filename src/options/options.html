    Why each permission is needed

    Storage
    Keeps your profiles, headers and settings on this device.
    Read and change data on the sites you visit
    A header can only be changed on a site the browser lets the extension act on, and this is also how a profile limited to the active tab knows which tab that is. Nothing is read from the page and nothing is sent anywhere.
    Header rules
    The browser applies your rules itself, so the extension never sees the traffic it changes.
    Web requests
    Firefox needs the older blocking request API to change response headers.

    Reset

    Restoring defaults removes every profile and header, clears the request log and puts the settings back the way they started.
